# Clinical demo media

The `demo-study.inv` file and rendered views come from one dental CBCT study. The subject authorized their use for this project's demonstration. The MIT license covers the software. Reuse of the study and its renderings outside this demonstration requires separate permission.

The demo keeps the original JPEG 2000 image blocks and the geometry and display parameters needed by INV Viewer. The source header is replaced with an allowlisted header. The anatomy in the volume is still the subject's anatomy.

This notice also covers the 1.14.0 native screenshots, hero/poster images, animated GIF and MP4 demonstrations in this directory. They show the same authorized clinical study. Tool-call transcripts contain viewing/rendering state; they do not include patient names, notes or source file paths. See [capture provenance](../demo-production.md).
