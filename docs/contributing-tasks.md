# Places to start

Start with one of these tasks:

- **Try the build on another Mac.** Record the macOS version, chip and build result, then check that the bundled demo opens. Report any step that failed or needed clarification.
- **Check text at the minimum window size.** Look for clipped labels in English and Russian. Include the window size and a reproduction using synthetic data.
- **Add a malformed DICOM fixture.** Pick one invalid length or truncated element, reproduce the error with a small generated file, and check that valid fixtures still pass.
- **Report a compatible export.** Include the export settings and format details in the compatibility form, without attaching patient data.

Check open issues before starting, and read [contributing](../CONTRIBUTING.md) for the build and test workflow.
